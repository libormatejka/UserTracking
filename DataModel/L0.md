# L0 — Raw Events

Surová event-level data z GA4 BigQuery exportu, sjednocená přes všechny dny.

- **Granularita:** 1 řádek = 1 event
- **Schéma:** [`DataSchema/L0.json`](../DataSchema/L0.json)
- **SQL:** [`SQL/L0/`](../SQL/L0/)

## Skupiny polí

### Identifikace eventu
| Pole | Typ | Popis |
|---|---|---|
| `UNIQUE_EVENT_ID` | STRING | Unikátní ID eventu |
| `EVENT_DATE_UTC` | DATE | Datum eventu (UTC) |
| `EVENT_TIMESTAMP_UTC` | INTEGER | Timestamp eventu v mikrosekundách (UTC) |
| `EVENT_DATETIME_UTC` | DATETIME | Datetime eventu (UTC) |
| `ACTUAL_TIMESTAMP_UTC` | INTEGER | Skutečný timestamp odeslání |
| `EVENT_NAME` | STRING | Název eventu (page_view, click, scroll, ...) |

### Identifikace uživatele / session
| Pole | Typ | Popis |
|---|---|---|
| `USER_PSEUDO_ID` | STRING | Anonymní ID uživatele (GA4 client_id) |
| `BROWSER_ID` | STRING | ID prohlížeče |
| `GA_SESSION_ID` | STRING | ID session |
| `GA_SESSION_NUMBER` | INTEGER | Pořadové číslo session pro daného uživatele |

### GTM / GA4 metadata
| Pole | Typ | Popis |
|---|---|---|
| `GA4_STREAM_ID` | STRING | ID datového streamu GA4 |

| `GTM_UNIQUE_EVENT_ID` | INTEGER | Unikátní ID eventu z GTM |
| `GTM_TAGNAME` | STRING | Název GTM tagu, který event odeslal |
